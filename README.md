# M3U Reader

Leitor de arquivos M3U para Android, feito em Kotlin.

## Como usar

1. Clone este repositório
2. Abra o projeto no **Android Studio** (File → Open → selecione a pasta)
3. Aguarde o Gradle sincronizar as dependências
4. Conecte seu celular via USB (com Depuração USB ativada)
5. Clique em **Run ▶** (Shift+F10)

## Configurar o celular

1. **Configurações** → **Sobre o telefone** → toque 7x em **Número da versão**
2. Volte e entre em **Opções do desenvolvedor**
3. Ative **Depuração USB**
4. Conecte o cabo USB e permita a depuração

## Tecnologias

- Kotlin
- Android SDK 34 (min SDK 24)
- AndroidX AppCompat
- Material Components
- ConstraintLayout
